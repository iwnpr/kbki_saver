# Сервис (добавить название сервиса) - qbch_db_saver_sdc
Сервис сохранения данных из QBCH_API (КБКИ)
## Структура
<hr>

### cache_lib
Библиотека для работы с распределденной системой кеширования Redis
<hr>

### db_lib
Библиотека для работы с БД. Под капотом EF Core npgsq
<hr>

### qbch_db_saver_sdc
Основное консольное приложение для считывания данных с кафки и записи в БД
<hr>
